**需要启动项目，但不用重新编译。** 一条命令会同时启动留形驱动、建图控制窗口和 RViz2。只想看实时点云的话，启动后直接看 RViz2 就行。想采集并保存地图，再点「运行 SLAM」。

### 1. 启动项目

在终端执行：

```bash
cd /home/leona/WorkingSpace/navigation2/project_slam
source install/setup.bash
ros2 launch odin_slam slam_bringup.launch.py
```

看到 `Device ready and streams activated`，就可以去 RViz2 看点云了。

### 2. 在 RViz2 看实时拼接

1. 在 `Global Options` 把 `Fixed Frame` 设为 `odom`。
2. 展开 `slam → slam_current → Topic`，确认话题是 `/odin1/cloud_slam`，把 `Reliability Policy` 改成 `Best Effort`。这一项显示最新一帧。
3. 勾选 `slam_deacy`（预设里的名称），也把它的 `Reliability Policy` 改成 `Best Effort`。把 `Decay Time` 设成 `30`，就能在同一个坐标系下看到最近 30 秒的点云。手持留形慢慢移动，画面会持续更新。

### 3. 采集并保存完整地图

在 `control_dialog` 窗口点 **运行 SLAM**，再拿着留形缓慢走一圈。结束后点 **暂停 SLAM → 保存结果**。RViz2 按 `Decay Time` 显示近期点云，建图节点会累加从点击「运行 SLAM」到暂停期间采集的点云。当前代码在保存时才输出这份完整地图。

每次重启后第一次保存都会写到 `maps/1.pcd`，要保留现有地图的话，先把它另存。保存后可以直接打开：

```bash
pcl_viewer maps/1.pcd
```

如果你要的是**整张累计地图在 RViz2 里随着走动持续更新**，需要给建图节点加一个累计点云发布话题，再让 RViz2 订阅。现有配置可以先用 `slam_deacy` 看实时拼接。
